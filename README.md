# ☕ Qspider Java Learning Exercises

A collection of Java programs written during my training at **Qspider**, covering core Java concepts from basics to advanced topics.

## 📚 Topics Covered

| Topic | Description |
|-------|-------------|
| **OOP** | Classes, Objects, Inheritance, Polymorphism, Abstraction |
| **Collections** | List, ArrayList, Comparator |
| **Comparable** | Sorting with Comparable interface |
| **Generics** | Generic classes and methods |
| **IsA / HasA** | Inheritance vs Composition |
| **Method Reference** | Java 8 method references |
| **Array** | Array operations and programs |
| **Non-Primitive Type Casting** | Upcasting and Downcasting |
| **Singleton Pattern** | Early & Lazy Instantiation |
| **toString Method** | Overriding toString() |
| **Library Management System** | Mini project |

## 🛠️ Tech Stack
- **Language:** Java
- **IDE:** VS Code / Eclipse
